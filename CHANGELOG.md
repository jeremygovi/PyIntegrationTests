# Changelog

This project follows Semantic Versioning. It is currently alpha and public APIs may change
before 1.0.0.

## 0.1.0a1

- Initial generic YAML engine, pytest collector and CLI.
- Helm, Kubernetes, AWS, Cloudflare, HTTP and DNS adapters.
- Explicit ownership journal, bounded cleanup recovery and redacted reports.
- Offline contract suite and opt-in Helm/Cloudflare examples.
